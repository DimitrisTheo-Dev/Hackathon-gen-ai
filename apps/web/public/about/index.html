About Castroom

A content studio that an existing agent and a person can operate together.

Castroom is a development-stage hackathon project for agencies, companies and individuals. Its purpose is to turn an approved brief into a small campaign with shared drafts, media, revisions and a clear review process.

One campaign, two interfaces

An external agent plans and orchestrates the work. A person uses the studio canvas and focused editor to inspect an item, improve a script or caption and review the final composition. The intended system keeps both interfaces on the same domain objects and permission checks. Private operations, rendering and publishing are still being integrated; development examples are visibly labelled and are not live production receipts.

People and implementation

Dimitris is building the studio, visual experience and public documentation. Minas is implementing the shared backend, MCP transport, durable execution and Humanlike integration. The code repository remains private. The maintainer’s public profile is DimitrisTheo-Dev on GitHub.

References and attribution

The warm, restrained interface composition is inspired by Moonjar, with original Castroom branding and product content. The example brief references Quintessential’s published BeWell Festival case study. This is source material, not an endorsement or partnership. Humanlike is the intended rendering integration; no claim is made about Quintessential’s internal AI system.

Current evidence

Read public API documentation and capability status for the implemented surface and its limits. Castroom does not advertise a paid plan, measured return on investment, engagement uplift or security certification.
