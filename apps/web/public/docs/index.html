Castroom API and agent documentation

Your agent makes the plan. Castroom gives it a place to work.

Castroom is a shared content studio for an agency, company, or individual. Its intended workflow connects an existing AI agent to brand context, authorized presenters, durable production jobs, and a human review surface.

Development preview

The studio is being connected to its production engine. Development fixtures are examples, not generated media or publishing receipts. A live MCP endpoint, authenticated client trial, and real publishing are not yet verified.

One campaign, two interfaces

The agent plans the campaign. The studio lets a person inspect and edit the same content. A script change needs a new render; changing a caption needs a new schedule review. Accepted background work must continue after a client disconnects.

  1. ConnectChoose a workspace and a scoped agent connection.
  2. Create and reviewPrepare three distinct avatar videos, refine the selected item, and inspect the final composition.
  3. Authorize the scheduleReview exact media, copy, accounts, disclosures, and times before submission.

Credits and provenance

Castroom is original hackathon work. The studio’s spatial direction is inspired by Moonjar. Humanlike is the intended rendering integration, implemented by Minas. The demo brief draws on Quintessential’s published BeWell Festival case study. Quintessential, BeWell, and Doctoranytime have not endorsed this demo or entered a partnership with Castroom.

The interface builds on React, TypeScript, Vite, and Supabase’s JavaScript client. See the repository dependency manifests and applicable package licences. This is a development product; no paid plan or commercial performance claim is offered.
