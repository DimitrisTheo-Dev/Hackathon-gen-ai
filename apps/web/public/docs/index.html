Faceful API and agent documentation

Your agent makes the plan. Faceful gives it a place to work.

Faceful is a shared content studio for an agency, company, or individual. People and their AI agents work on the same projects: briefs, draft scripts, versions, presenters, render jobs and schedule reviews.

Check what this deployment has switched on

Integration status is derived from the deployment’s configuration. Where the engine is configured, the authenticated campaign API, scoped workspace tokens and the MCP endpoint are available, and drafting is free. Publishing is not available anywhere yet. Rendering needs a recording worker; until one is attached, render requests are refused, not simulated. Development fixtures are examples, not generated media or publishing receipts.

One campaign, two interfaces

The agent plans the campaign. The studio lets a person inspect and edit the same content. A script change needs a new render; changing a caption needs a new schedule review. Accepted background work must continue after a client disconnects.

  1. ConnectChoose a workspace and a scoped agent connection.
  2. Create and reviewDraft up to three avatar videos, refine the selected item, and render it once a renderer is attached.
  3. Review the scheduleCheck exact media, copy, accounts, disclosures, and times. Nothing is posted yet: no publishing destination is connected.

For agents and integrators

These pages contain their useful content in initial HTML. The documentation index points to public guidance. The public OpenAPI specification documents implemented read-only status, permission definitions and documentation routes. API documentation and the repository CLI need no credentials. Where the engine is configured, an agent can work in the same workspace through the MCP endpoint.

Credits and provenance

Faceful is original hackathon work. The studio’s spatial direction is inspired by Moonjar. Humanlike is the intended rendering provider, an integration led by Minas; the recording worker that turns its realtime avatar sessions into video files is not attached yet. The demo brief draws on Quintessential’s published BeWell Festival case study. Quintessential, BeWell, and Doctoranytime have not endorsed this demo or entered a partnership with Faceful.

The interface builds on React, TypeScript, Vite, and Supabase’s JavaScript client. See the repository dependency manifests and applicable package licences. This is a development product. Billing, where configured, runs in Stripe sandbox (test mode) only, so no real charge is possible, and no commercial performance claim is offered.
