Connect your agent

Bring the agent you already use.

Codex CLI and Claude Code are the two clients that have been tried. This page covers the workspace-token path. OAuth sign-in works on production with a scripted client but has not yet been tried through a host’s own sign-in screen; it is described on the MCP page.

  • Live Workspace tokens
  • Not trialled OAuth sign-in
Check this deployment first

These steps work where integration status reports engine.mcp: true. Elsewhere /mcp answers 503 and they cannot complete. Never use a Supabase key or a publisher credential as an MCP token. No two-minute setup claim has been measured.

Create a workspace token

  1. Sign in to the studio as a workspace owner or admin and open Connect your agent.
  2. Create a named workspace token with only the permissions the agent needs and an expiry of at most 90 days. It is shown once; Faceful stores only its SHA-256 digest.
  3. Keep the token in your secret manager or shell environment, out of prompts, URLs, recordings and git.

The examples use https://faceful.vercel.app/mcp. If you open the studio on a different origin, use that origin’s /mcp.

Confirm the connection

Ask the agent to call list_projects and get_billing_status. A real connection returns your workspace’s projects and credit balance, and the studio’s connection list records when the token was last used. Copying a command or seeing a server in local configuration is not a successful connection.

What has been tried

Codex CLI 0.169.0 and Claude Code 2.1.325 connected with a workspace token against a local engine server backed by the real Supabase project, with the configuration passed per run. On 14 November 2026 Claude Code was run against the production endpoint with a workspace token, and the OAuth path (discovery, client registration, consent page, token, refresh) was completed on production with a scripted client. OAuth has not yet been tried through a host’s own sign-in screen. Other MCP clients are untested: Streamable HTTP support alone does not establish authentication or workflow compatibility.
