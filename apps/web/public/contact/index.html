Contact the Faceful project

Reach the maintainer with a clear, non-sensitive description.

Faceful is a small development project. The current public contact route is the maintainer’s GitHub profile. No dedicated support email, telephone number or business address has been published for this project.

Project collaboration

If you already have access to the private repository, use the existing project collaboration channel to report a problem or discuss integration. Judge access is handled through the organizer’s announced process; repository visibility is not changed simply to make public documentation easier to find. Do not assume public access to the code from a link to the maintainer’s profile.

Useful details to include

Describe the page or public endpoint, the action you attempted, the time and timezone, the visible error code and the result you expected. A short reproduction using fictional content is usually sufficient. If a real job exists, an authorized collaborator can provide its object ID and revision through a private channel.

Keep credentials private

Do not post API keys, agent tokens, browser cookies, private campaign text, signed media URLs or customer files in a public issue or message. For an access problem, describe the permission that is missing rather than sharing the credential. The public discovery API does not need any credential.

Before requesting an integration

Check formats and limits, MCP availability and error recovery. Rendering and publishing providers are not connected yet, so a UI preview alone does not establish that a publishing or rendering action is available.
