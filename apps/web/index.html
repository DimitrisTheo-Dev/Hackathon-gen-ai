Castroom: a content production studio for your agent

Create campaigns with your agent. Fine-tune them here. Castroom gives people and their external agents one place to work on company briefs, content drafts, video versions and schedule reviews.

One campaign, two interfaces

Codex or Claude Code can plan a multi-item campaign through the intended MCP interface. The visual studio provides a focused editor for the selected script, authorized presenter, channel caption and requested schedule. You can also create drafts manually from supplied company context.

Current development status

The studio and public documentation are implemented. The shared backend, authenticated MCP setup, Humanlike rendering and publishing providers are not integrated yet. Example drafts are available only in explicit development previews; they are not generated videos or accepted publishing jobs.

Setup and capabilities

Read the Codex and Claude Code setup templates, supported formats and current limits, authentication and approval model, and recoverable errors. No working MCP or OpenAPI endpoint is advertised before the engine is ready.
